# Galpão Monitored - Sistema de Triagem Logística

Repositório oficial de distribuição e atualização automática pela nuvem.

## 🚀 Funcionalidades
- Suporte a Anjun Express, iMile e Loggi (Arco)
- Triagem com conferência e atribuição de motoristas
- Proteção e licenciamento por Hardware ID (HWID)
- Auto-atualização transparente pela nuvem

## 🔒 Segurança
Este repositório contém apenas os códigos operacionais do sistema.
Dados de clientes, bancos de dados locais, chaves criptográficas e credenciais não são armazenados na nuvem.
